# Football Recommendation System

Deskripsi
Aplikasi manajemen data club sepak bola berbasis Python menggunakan struktur data Linked List, Stack, Queue, dan GUI Tkinter.

 Fitur
- Tambah club
- Update club
- Hapus club
- Cari club
- Urutkan poin
- History pencarian (Stack)
- Watchlist (Queue)

 Teknologi
- Python
- Tkinter
- Linked List
- Stack
- Queue
