# FOOTBALL RECOMMENDATION SYSTEM

## DESKRIPSI
Aplikasi ini merupakan sistem rekomendasi klub sepak bola Eropa berbasis Python dengan GUI Tkinter.  
Sistem ini digunakan untuk mengelola data klub serta memberikan rekomendasi berdasarkan poin menggunakan struktur data dan algoritma.

---

## FITUR APLIKASI
- Tambah data klub (Create)
- Update data klub
- Hapus data klub
- Menampilkan semua data klub
- Pencarian klub berdasarkan nama
- Pengurutan klub berdasarkan poin tertinggi
- Rekomendasi Top 3 klub
- History pencarian (Stack)
- Watchlist (Queue)

---

## MATERI YANG DIIMPLEMENTASIKAN

### 1. Object Oriented Programming (OOP)
- Class Club
- Constructor (__init__)
- Method tampil()

### 2. Linked List
- Node
- Insert data (tambah)
- Delete data (hapus)
- Update data
- Traversal data

### 3. Stack
- Push data
- Penyimpanan history pencarian

### 4. Queue
- Enqueue data
- Penyimpanan watchlist

### 5. Searching Algorithm
- Linear search berdasarkan nama klub

### 6. Sorting Algorithm
- Bubble sort berdasarkan poin klub

### 7. GUI Tkinter
- Button
- Label
- Entry
- Listbox
- Frame
- Event handling (command)

---

## STRUKTUR DATA YANG DIGUNAKAN
- Linked List → penyimpanan data klub
- Stack → history pencarian
- Queue → watchlist

---

## ALGORITMA YANG DIGUNAKAN
- Bubble Sort → mengurutkan poin klub
- Linear Search → mencari klub berdasarkan nama
- Traversal Linked List → menampilkan semua data
